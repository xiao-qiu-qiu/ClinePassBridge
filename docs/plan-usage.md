# 套餐用量

在「配置概览 → 凭据与套餐用量」查看 Cline 账号的套餐名称、当前订阅周期，以及 5 小时、每周、每月的已用百分比和重置时间。时间按浏览器本地时区显示，百分比使用 Cline 返回值；缺失值显示 `—`，不当作零用量。

凭据按名称排序，每页 12 个，可搜索名称或 ID。支持单个刷新和刷新本页。页面可见时，当前页约每分钟更新；后台页、其他配置页和未显示的凭据不自动查询。后台合并同一凭据的并发查询，同时最多查询 3 个凭据，常规结果缓存 60 秒，手动刷新保留 10 秒最小间隔，套餐名称和周期缓存 5 分钟。

查询失败保留上次成功数据并显示时间、过期状态和原因；首次失败显示未知，不显示为 0%。更换 API Key 后旧缓存失效，旧请求的结果也不会覆盖新 Key。暂停的凭据不自动查询。用量查询不会参与模型推理、凭据轮转或冷却。

这是账号整体套餐用量，包含账号在其他客户端的使用。同一账号的多个 Key 可能共享同一套餐，请勿累加额度。用量重置时间与订阅周期截止时间分别取自各自接口，不混用，也不将百分比换算成剩余 token 或美元。

## 接口与兼容性

- 插件管理接口：`GET /v0/management/clinepassbridge/credentials/usage?id=<凭据ID>`，手动刷新可加 `refresh=1`，由 CPA 管理鉴权保护。
- 官方来源：`GET https://api.cline.bot/api/v1/users/me/plan/usage-limits` 和 `GET https://api.cline.bot/api/v1/users/me/plan`。使用现有凭据的 Bearer API Key；Key、上游账号 ID、订阅 ID 不返回前端，用量缓存仅保留在内存。
- 上游鉴权失败、限流、超时等以该凭据的查询状态返回，不会误触发 CPA 管理密钥登录弹窗。
- 官网接口尚未确认有公开稳定性保证。未知用量窗口仍显示，缺字段或接口异常显示提示。
- 查询使用 CPA 的宿主 HTTP 回调和全局代理配置。CPA v7.3.12 的该管理回调不接受凭据独立代理；若凭据设置了 `proxy_url`，界面会提示暂不支持用量查询，避免绕过指定代理发送 Key。此限制不改变已有模型请求的行为。

## 测试包

普通分支推送只触发 GitHub Actions 构建。可以在对应提交的 workflow run 中下载 `package-linux-amd64` 等平台产物进行测试；正式市场安装仍取已有 Release。测试阶段不创建版本 tag 或 Release。

建议验收：检查实际账号的三档用量；添加多账号后检查搜索、翻页和单独刷新；编辑 Key 后确认数据随之更新；切换 CPA 明暗主题和窄屏检查布局。
